# 编码规范

## 注释语言

- 所有代码注释必须使用**中文**（简体），包括：
  - 函数/类的 docstring
  - 行内注释（`# ...`）
  - 模块级文档字符串
- 禁止使用英文注释，团队成员不一定能看懂英文注释
- 已有的英文注释不主动修改（避免 diff 噪音），但新增和修改的注释必须是中文

## 代码风格

- 遵循 PEP 8 规范
- 导入顺序：标准库 → 第三方库 → 项目内部模块
- 避免在注释中重复代码逻辑（不要写"导入模块"、"定义函数"之类的废话注释）
- 注释应解释**为什么**这么做，而不是**做了什么**
